# BART Brand Identity Template v0.0.2 trial

This trial copies the [released kit](https://github.com/vixttha/Brand-Identity-Template/releases/tag/v0.0.2) at [`87d0f9aedbe69ca4b16815d6b3329efcf5889da9`](https://github.com/vixttha/Brand-Identity-Template/commit/87d0f9aedbe69ca4b16815d6b3329efcf5889da9). BART adaptations inside the copy are the project brief, creative decision and empty project inventory. The existing [Facet drafts](https://github.com/vixttha/Blender-Agent-Refinement-Toolkit/tree/9741c63beaa237ab6fcd3672e2dff5e49e759b5b/brand-identity) are the historical comparison.

## How agent identity became brand identity

1. [The naming decision](https://github.com/vixttha/Blender-Agent-Refinement-Toolkit/issues/62) distinguishes **Blender-Agent Refinement Toolkit**, the toolkit people install, from **BART**, the agent they refer to when using it. “Give shape to an idea” expresses the product promise.
2. [The public rebrand](https://github.com/vixttha/Blender-Agent-Refinement-Toolkit/pull/67) put those names into the public README and active documentation. [Instructions HQ](https://github.com/vixttha/Blender-Agent-Refinement-Toolkit/pull/73) records the same distinction in project instructions. **Archivewright** is the instructions stewardship role.
3. [The visual branch](https://github.com/vixttha/Blender-Agent-Refinement-Toolkit/tree/9741c63beaa237ab6fcd3672e2dff5e49e759b5b/brand-identity) gave the name a Facet logo, wordmark, palette and application examples. The trial asks how well those choices communicate what BART does on a small GitHub avatar and in the product documentation.

## Trial creative direction

The [decision record](brand-identity/01-strategy/creative-decision.json) screens categories and compares three written options using the released rubric.

| Concept | Score | Main trade-off |
| --- | ---: | --- |
| Section Line | 90 | Distinct opening must survive at 16 px |
| Mesh Joint | 87 | Smaller counters may fill at favicon size |
| Reference Frame | 78 | Open frame may resemble a crop icon |

Section Line is the trial recommendation. The artwork confirmation field is intentionally empty while the owner reviews the concept and exact wordmark text.

## Trial checks

The public runner executes the released regressions, runs the kit against the BART brief and decision, and exercises legacy draft import in a temporary copy. Simulated confirmation exists only in the temporary copy. The runner reports the exact checkout and separate findings for draft handoff and relative evidence links.
