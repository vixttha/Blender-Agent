# BART trial brief

BART is the agent for **Blender-Agent Refinement Toolkit**, a local Python CLI and MCP toolkit for inspecting, creating, converting, and repairing 3D assets. Primary readers are developers and technical artists using GitHub and the documentation. Start with the repository avatar at 32 and 64 px in light and dark context. Use a simple one-color silhouette and keep the full product name available as live text nearby.

Tie the direction to real geometry, such as reported bounds, joined mesh faces, or a sectional view. The public line is “Give shape to an idea.” Treat new concepts as proposals and record any possible misread at the first placement.
