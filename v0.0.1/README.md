# Code Stack v0.0.1

1. Copy this folder's contents to your project. Set the title, canonical repository URL, and activation links in its README. Keep Stack's role portable.
2. Pin the application commit and run discovery. Replace the example registry, then record the actual stack, supporting formats, conditional choices, and source evidence.
3. Write the first audit and link its runtime evidence. Add proposal records for open decisions. Keep durable context in STACK_MEMORY.md.
4. Run the portable checks using your runner policy. Adapt the parent branch's workflow when you want CI for a concrete repository. Check out the audited application under a separate path.
5. Give a fresh agent the hub README URL and ask it to read Code Stack and work as Stack.

The JSON states are `active` for current use, `conditional` for a documented trigger, `research` for discovery, and `retired` for removed choices. Record decision authority and scope separately from observed source usage.
