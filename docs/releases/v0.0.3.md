Blender-Agent v0.0.3 is a pre-alpha Python CLI and optional MCP stdio adapter for inspecting, creating, converting, and repairing 3D assets with headless Blender.

## Changes

- OBJ exports include the matching MTL file. The CLI and MCP protect existing destinations by default, and the installed-wheel test verifies that an assigned color survives Blender re-import.
- Mesh repair processes each shared editable mesh once. Blender rejects faceless input before export, and the host structurally checks staged STL and OBJ outputs within its inspection limit.
- ASCII STL inspection streams facets, OBJ inspection accepts continued face records, and MCP requires an explicit workspace. The MCP session can respond to inspection while one Blender job runs.

## Tested configurations

| Check | Public runner configuration |
| --- | --- |
| Python CLI and unit tests | Python 3.11 and 3.12 on Ubuntu and Windows |
| Installed-wheel MCP stdio | Python 3.12 on Ubuntu and Windows. The optional adapter requires MCP SDK 1.30.0 or later in the v1 series. |
| Real Blender through MCP | Blender 4.1.0 and 4.5.0 on Ubuntu, and Blender 4.5.0 on Windows |

## Limits

- Use a trusted workspace and trusted assets. Blender can access external resources with the permissions of its process. An exported `.blend` file should be handled with the same trust as its source.
- Geometry and bounds are structural summaries. Multi-scene files can include counts from outside the active scene. These checks do not establish printability or production readiness.
- Active MCP cancellation was verified on Ubuntu. Equivalent Windows coverage, the installed-wheel MCP workflow on Python 3.11, and named desktop MCP hosts still need verification.
