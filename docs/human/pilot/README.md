# Mira Vale · Mist still-image pilot

The `Human` branch carries this test of the edit while HeyGen's monthly Avatar IV allowance is exhausted. The video is an 18-second silent composition with the supplied script displayed as timed text. The locked headshot is used byte-for-byte. The full-body draft is outside the edit.

| Time | Picture |
| --- | --- |
| 0–8.8 seconds | Mira's Mist headshot, the still-image label, and the three script captions |
| 8.2–15.1 seconds | Wireframe illustration and values captured from the real triangle walkthrough |
| 14.55–18 seconds | BART and “Give shape to an idea.” |

The public Ubuntu workflow runs the existing CLI and MCP walkthrough, builds the evidence panel from its captured JSON, checks the composition, and renders it with HyperFrames 0.9.69. It decodes the MP4, checks picture dimensions, frame rate and duration, and captures five review frames. The run artifact holds the MP4, review frames, inspection result, media probe and checksum. The pilot does not exercise speech, lip sync or contact-lens stability in motion.
