# Move a project installation from Code Stack v0.0.1

1. Preserve your existing registry, receipt and audited commit so historical claims remain reproducible.
2. Copy the new kit into the candidate installation. Change schema_version to 2 in the new registry.
3. Add a basis to every technology. Replace tracked_language with basis language for tracked programming languages. Use format for declared supporting files, source for embedded or runtime technology with a repository-file reference, and proposal for conditional or research ideas.
4. Add kind and review to each evidence record. Repo-file records carry path and the audited commit. CI records carry their tested commit. A reviewed record carries reviewed_on. Use unchecked for evidence that still needs a human review.
5. Convert reviewed_paths from a list into a path-to-reason map. Convert each language override string into an object with kind language, name, and reason. Re-run discovery to account for ownership categories and embedded formats.
6. Supply comparison refs if the runner has the relevant history, and retain the audit receipt. Check the source revision and the existing application CI separately from the hub’s inventory audit.

The CLI keeps the earlier discovery and registry entrypoints. Schema v1 registries remain reproducible with the archived v0.0.1 checker.
