## Install and verify in ChatGPT

1. In the Blender-Agent Refinement Toolkit project, open **Project settings**. Save a private copy of the current instructions for rollback.
2. Open the [copy-ready instructions](CHATGPT_PROJECT_INSTRUCTIONS.md) at the maintainer-approved commit. Copy the entire file into Project settings and save.
3. Reopen Project settings. Compare the entire saved text with the pinned file, including the version, three canonical links, and product and agent names. Record the version and source SHA privately.
4. Start one fresh chat in the project. Ask it to identify the product and agent, verify the live `main` SHA and relevant open PRs, and recommend one scoped next action with its public-runner checks. Ask for GitHub read-only discovery and for the Graphify route or fallback. Verify the actual reads and the absence of write actions.
5. Record settings read-back and fresh-chat behavior separately. Keep private project links and screenshots outside the public archive. If an authorized settings session is unavailable, record both checks as pending. To roll back, restore the privately saved text and reopen settings to confirm it.
