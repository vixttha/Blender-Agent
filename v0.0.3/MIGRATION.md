# Migrate an earlier Code Stack installation

Run the new [one-run review](AUDIT.md) at the source ref you want to assess. It generates a new schema 3 registry and leaves your archived reports available at their original commits. Transfer earlier owner decisions with the approval input after checking their component and role in the new report.

For a schema 2 installation, keep using the legacy auditor with the existing registry. A [schema 2 example](registry.example.json) is included for reference. Follow the archived [v0.0.2 migration guide](../v0.0.2/MIGRATION.md) if you need to update a schema 1 registry for the legacy entry point.
